## Features

- Unified dashboard for Jira issues, Confluence pages and Trello cards in one window
- Offline cache of boards and pages with automatic sync when the connection returns
- Native desktop notifications for issue assignments, mentions and due-date reminders
- Built-in quick-create panel for logging bugs, tasks and comments without opening a browser
- SSO and two-factor authentication support with encrypted local credential storage
